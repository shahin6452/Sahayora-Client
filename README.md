# Sahayora

**Together, We Make a Difference.**

Sahayora is a community-driven platform that connects people through social development activities and volunteering opportunities.

**Live Website:** `https://YOUR-LIVE-URL.vercel.app`

## Features

- **User Authentication:** Secure registration and login with email/password and Google authentication.
- **Explore Events:** Browse upcoming social development events with search and category filters.
- **Create Events:** Logged-in users can create community events with descriptions, images, locations, and dates.
- **Join Events:** Users can join or leave events and view confirmed volunteers.
- **Joined Events:** View and manage events you have joined.
- **Manage Events:** Organizers can update or delete their own events.
- **Community in Action:** Explore completed community events.
- **Responsive Design:** Optimized for desktop, tablet, and mobile devices.
- **Notifications:** Receive success and error notifications for important actions.

## Technologies Used

- Next.js
- React
- Tailwind CSS
- Node.js
- Express.js
- MongoDB
- Mongoose
- Better Auth

## Purpose

Sahayora aims to make community participation easier by bringing volunteers and social development opportunities together on one platform.
